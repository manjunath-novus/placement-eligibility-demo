# Eligibility Evaluation Checklist

Use this checklist when reviewing an eligibility result against a placement drive.

## Before evaluating

- [ ] Confirm that the student profile and drive details refer to the same recruitment cycle.
- [ ] Read every criterion stated by the drive.
- [ ] Distinguish required criteria from preferences or descriptive information.
- [ ] Identify required fields that are missing from the student profile.

## Evaluate each criterion

- [ ] Compare CGPA against the stated minimum, using the drive's exact scale.
- [ ] Check branch or degree restrictions against the explicitly listed values.
- [ ] Check active and historical backlog rules separately.
- [ ] Check graduation year, batch, and any stated gap restrictions.
- [ ] Check work experience or internship requirements only when the drive specifies them.
- [ ] Do not infer unstated restrictions from other companies' drives.

## Choose the result

| Situation | Result |
|---|---|
| Every stated required criterion is satisfied | Eligible |
| At least one stated required criterion is not satisfied | Not eligible |
| A required value is missing or ambiguous, so the comparison cannot be made | Need more info |

If a required value is missing, name the exact field needed rather than assuming a value.

## Explain the result

A useful result should include:

1. The verdict.
2. Each criterion checked.
3. The student's value and the drive's requirement.
4. A short reason for every failed or unresolved criterion.

## Review and safety

- [ ] Verify boundary conditions (for example, exactly the minimum CGPA).
- [ ] Ensure all required criteria were evaluated, not just the first match.
- [ ] Keep the result traceable to the source drive information.
- [ ] Make clear that sample data is illustrative and does not represent an official company decision.
